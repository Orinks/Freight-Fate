# The Thing, both directions -- 2026-09-30

Bowlin's The Thing is at I-10 Exit 322, Dragoon, Arizona (bowlintc.com).
Bowlin's says 247 billboards announce it between Tucson and El Paso, so the
countdown runs both ways. Every `leg:` is written the way the driver reads
the sign; `at_mi` counts from that end.

Westbound the Las Cruces leg already carries a three-sign countdown; the El
Paso leg gets the same three at the same distances out. Sign two's "a dollar
or two" is now "a few dollars": admission is five dollars (Bowlin's, 2026).
Eastbound from Tucson, Exit 320 is the Texas Canyon rest area two miles
before Exit 322, and the Dragoon Pass callout sits between them, so the last
eastbound sign stands before the rest area and says so.
