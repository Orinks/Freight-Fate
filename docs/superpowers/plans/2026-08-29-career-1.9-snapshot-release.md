# Career 1.9 Snapshot Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish complete Career 1.9 snapshot builds that ordinary players can download, extract, run, and update without manually fetching music or native libraries.

**Architecture:** A stable `dev.orinks.net` route redirects to a verified public Vercel Blob containing `music.pak`. Freight Fate's release tool consumes that stable URL, prepares pinned BASS libraries automatically, and a dedicated changelog-gated GitHub Actions workflow publishes `1.9-tester-*` prereleases from `feat/career-1.9` until the release line moves to `dev`.

**Tech Stack:** Python 3.12, uv, Rust/Cargo, PowerShell, GitHub Actions, GitHub Releases, Next.js 15, TypeScript, Vitest, Vercel Blob

**Spec:** `docs/superpowers/specs/2026-08-29-career-1.9-snapshot-release-design.md`

## Global Constraints

- Build Career 1.9 snapshots from `feat/career-1.9` until 1.9 is merged, then change the workflow source to `dev`.
- Keep the existing 1.8 `nightly-*` workflow intact until that transition.
- Use the stable public URL `https://dev.orinks.net/downloads/music.pak`.
- Never commit `music.pak` or BASS binaries to either Git repository.
- Require SHA-256 verification before downloaded assets enter a build.
- Windows is the required initial Career 1.9 release platform.
- A release must contain music, BASS, SDL2, Prism, applicable licenses, data, documentation, and checksums.
- Players download, extract, and run; they never set build environment variables or stage DLLs.
- Source builders may be required to install Git, Rust, and `uv`, but the repository script must not install system-wide software or request administrator privileges.
- Preserve user saves and the currently installed game when an update fails.
- Use curated `CHANGELOG.md` entries for release notes, never raw commit subjects.
- Keep player-facing documentation concise and screen-reader friendly.

```ts
export function getFreightFateMusicBlobUrl(
  env: NodeJS.ProcessEnv = process.env,
): URL {
  const raw = env.FREIGHT_FATE_MUSIC_BLOB_URL;
  if (!raw) {
    throw new Error("FREIGHT_FATE_MUSIC_BLOB_URL is not configured");
  }
  const url = new URL(raw);
  if (
    url.protocol !== "https:" ||
    !url.hostname.endsWith(".public.blob.vercel-storage.com") ||
    url.pathname !== "/freight-fate/music.pak"
  ) {
    throw new Error("FREIGHT_FATE_MUSIC_BLOB_URL must name the public Freight Fate music blob");
  }
  return url;
}
```

import { NextResponse } from "next/server";
import { getFreightFateMusicBlobUrl } from "@/lib/freight-fate-downloads";

export async function GET() {
  try {
    return NextResponse.redirect(getFreightFateMusicBlobUrl(), {
      status: 307,
      headers: { "Cache-Control": "public, max-age=300" },

}
